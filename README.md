# BRS Station

Україномовний сайт автосервісу у Львові. Статичний HTML / CSS / JavaScript без залежностей. Публікація через GitHub Pages з кореня гілки `main`.

## Перегляд

```sh
node tools/serve.mjs
```

Локальна адреса: http://127.0.0.1:4173/

## Вміст

- `index.html` — послуги, контакти, FAQ та семантична розмітка.
- `style.css` — адаптивні стилі / Unbounded 700 та Onest / темна тема.
- `script.js` — меню й доступне модальне вікно запису.
- `assets/` — власні ілюстративні зображення та локальні шрифти.

Запис відкриває підтверджені телефони та Instagram. Сайт не зберігає заявки, не імітує підтвердження запису та не має бекенду.
